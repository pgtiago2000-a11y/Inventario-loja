Como usar no iPhone

1. Importar do Eticadata: Exporte os artigos para Excel/CSV e importe aqui pelo botão Importar.

2. Ler Código de Barras: Toque em Ler Código de Barras e aponte a câmara para o EAN. Em etiquetas pequenas, afaste um pouco o iPhone para focar melhor.

3. Artigos sem EAN: Pesquise pela referência curta (ex: 21011 ou C16) e toque no artigo para somar a quantidade.

4. Exportar: No final, toque em Exportar Inventário para gerar o ficheiro Excel/CSV pronto a importar no Eticadata.
